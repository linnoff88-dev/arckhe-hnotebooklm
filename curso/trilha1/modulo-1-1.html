📱 Agente que vive no chat

Hermes não é um app que você abre. É um bot do Telegram conectado ao seu computador. Você manda mensagem como se fosse pra um amigo, ele executa na sua máquina e responde no mesmo chat. A interface é assíncrona: você pergunta agora, ele responde em 10s ou em 10 minutos, dependendo da tarefa.

💡 Por que Telegram em vez de app dedicado

  • •Já está no seu bolso. Sem instalar nada novo. Sem aprender UI.
  • •Síncrono e assíncrono no mesmo lugar. Texto rápido, voz, foto, anexo — tudo serve como input.
  • •Histórico permanente. Pesquisável anos depois. Seu próprio log de pedidos.
  • •Multi-device gratuito. Mesma conta no celular, tablet, desktop.

✓ Hermes resolve

  • ✓"Cria notebook X e adiciona essas 3 URLs"
  • ✓"Manda email pro João com o brief de ontem"
  • ✓"Agenda lembrete pra revisar pitch terça 9h"
  • ✓"Roda o workflow de relatório semanal agora"

✗ Hermes NÃO faz

  • ✗Substituir reuniões humanas (mas resume)
  • ✗Tomar decisões estratégicas sem você
  • ✗Operar sem soul.md (vira chatbot genérico)
  • ✗Funcionar sem conexão com seu computador

🧬 Soul.md — a alma do agente

Arquivo único em ~/.hermes/soul.md descrevendo quem você é, o que faz, como gosta de trabalhar, suas decisões já tomadas e seus hard nos. Hermes carrega esse arquivo em toda interação. Sem ele, é só mais um chatbot. Com ele, é seu chefe de gabinete.

⚡ Dica prática

A primeira versão do seu soul.md deve ter no mínimo:

## Identity — nome, role, cidade
## Mission — meta do ano em UMA frase
## Voice — 3 adjetivos da sua escrita
## Hard nos — 3-5 coisas que Hermes nunca pode fazer

Refina ao longo dos meses. Especificidade compõe.

1

Mês 1 — fundamentos

Preencher Identity, Mission, Voice. Suficiente pra Hermes parar de soar genérico.

2

Mês 2-3 — refinamento

Adicionar Business (números), Rhythm (quando você foca), Memory (decisões tomadas).

3

Mês 6+ — manutenção

Update mensal das métricas. Adicionar lessons learned por trimestre.

🔌 Skills — extensões plugáveis

Skill é um arquivo .md com frontmatter (name + description) e instruções. Quando seu pedido casa com a description, Hermes carrega aquele conteúdo e segue as ordens. NotebookLM é uma skill. Hermes Triad é uma skill. /wrapup é uma skill.

📊 Por que skills são revolucionárias

  • Discovery automático: joga o .md numa pasta, Hermes encontra.
  • Ativação por intenção: não precisa decorar comandos, fala natural.
  • Isolamento: a skill só entra no contexto quando relevante. Não polui o prompt do dia a dia.
  • Composição: várias skills atuam no mesmo pedido sem conflito.
  • Versionamento simples: arquivo de texto. Git track, edit, fork.

🧠 Memória persistente

Hermes guarda fatos sobre você em arquivos de memória organizados por tipo. Quando você corrige ("nunca use menu interativo"), aquilo vira feedback memory permanente. Quando descobre algo novo do seu negócio, vira project memory. Sessões futuras carregam tudo.

📌 User memory

Quem você é. Role, expertise, preferências de comunicação.

🚦 Feedback memory

Correções e confirmações. "Não use X." "Sim, esse padrão funciona."

📋 Project memory

Contexto do projeto atual. Datas, decisões, restrições.

🔗 Reference memory

Pointers pra sistemas externos: Linear board, Slack channel, dashboard.

⚠️ O que NÃO virar memória

Código, convenções, arquitetura — já estão no projeto. Solução de bug — está no commit. Git history — está no log. Memória é pra contexto não-derivável do código.

🛠️ Tools — o agente AGE

Hermes não fica preso a "responder texto". Tem ferramentas reais: lê arquivos, escreve código, dispara comandos shell, faz HTTP, chama APIs via MCP. É a diferença entre ChatGPT que sugere e agente que executa.

Categorias de tools

Read/Write/EditManipular arquivos diretamente
BashExecutar comandos shell (com permissões)
WebFetchPegar conteúdo de URL
MCP serversNotebookLM, n8n, GitHub, Slack — qualquer coisa via Model Context Protocol
AgentDespachar sub-agente especializado pra subtarefa

🔐 Permissões e segurança

Cada tool tem nível de permissão. Você decide o que ele pode fazer sem confirmação. "Sempre permite ler arquivos." "Sempre pergunta antes de deletar." Configuração em ~/.hermes/settings.json.
