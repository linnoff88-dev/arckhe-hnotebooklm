⏰ Workflows agendados — relatórios automáticos

"Toda manhã 8h, briefing diário do meu segundo cérebro no email." Set once, run forever.

1

🕗 Schedule trigger

Node n8n. Aceita cron expression, intervalo simples ou day-of-week. Timezone configurável. Fundação de qualquer automação recorrente.

0 8 * * 1-5    # Seg-Sex 8h
0 17 * * 5     # Sexta 17h
*/30 * * * *   # A cada 30 min
2

📨 Email diário automático

Pipeline: cron → notebooklm ask → format HTML → Gmail/SES node → seu email. Acorda já briefado. O killer use-case.

3

🎧 Podcast diário no Telegram

Cron → generate audio --length short → wait → download → Telegram sendAudio. Você ouve voltando do trabalho.

⏱️ Tempo

Áudio leva 10-20 min pra gerar. Dispara 7h, chega no chat ~7:20. Você sai de casa 8h ouvindo.

4

🔄 Retro semanal

Sexta 17h: puxa wrapups da semana → adiciona ao AI Brain → gera report "Resumo da semana". Reflexão estruturada vira hábito automático.

5

📊 Monitor de competidores

Cron semanal scrape competidores → add as source → ask "o que mudou esta semana?" → manda diff no chat. Inteligência competitiva passiva.

6

🚨 Error handling e alertas

Try/catch nodes, error workflow global, alerta no Telegram quando falha. Workflow silencioso é workflow morto.

✓ Padrões

  • • Error Trigger workflow global
  • • Retry com backoff exponencial
  • • Alert em Slack/Telegram
  • • Idempotência (evita duplo envio)

✗ Erros comuns

  • • Workflow sem catch — falha silenciosa
  • • Retry infinito — drena cota
  • • Sem timeout — trava forever
