🔌 n8n + NotebookLM via MCP

Criar workflows complexos de automação conversando com Hermes.

1

🧬 MCP — Model Context Protocol

Protocolo aberto Anthropic. Define como agentes AI conversam com ferramentas externas. n8n, GitHub, Slack, NotebookLM — todos expõem MCP servers. Plug-and-play, não custom code.

📐 Arquitetura

Client (agente AI) ↔ JSON-RPC ↔ Server (CLI/API). Tools, Resources, Prompts são os 3 primitivos.

2

⚙️ Habilitar MCP no n8n

app.n8n.cloud → Settings → MCP → enable workflows. Pega server URL e bearer token. Cada workflow vira tool acessível pelo agente.

{
  "mcpServers": {
    "n8n": {
      "url": "https://your.n8n.cloud/mcp/sse",
      "headers": {"Authorization": "Bearer YOUR_TOKEN"}
    }
  }
}
3

🔑 Adicionar sem expor token

Hermes gera bash com placeholder, você troca pelo token, roda no terminal. Token nunca passa pelo chat. Segurança básica.

4

🛠️ Criar workflow conversando

"Cria workflow que toda manhã 8h pega insight do meu YouTube notebook e manda email." Hermes monta nodes, conecta, salva. Você descreve, ele constrói.

✓ O que Hermes monta bem

  • • Schedule trigger
  • • HTTP nodes
  • • Email/Slack send
  • • Code node simples
  • • Branches IF

✗ O que você ainda valida

  • • Credenciais (cada conta)
  • • Logic complexa multi-branch
  • • Rate limits específicos
  • • Custos de execução
5

🔍 Diagnóstico de execuções

"Por que o workflow X falhou ontem?" → Hermes puxa executions, analisa, identifica node problemático. Você não precisa virar engenheiro n8n.

6

🏗️ Workflow vs Hermes direto

Decisão importante: ação one-shot → Hermes resolve. Recorrente, multi-step, com gates visuais ou cliente vendo → n8n.
